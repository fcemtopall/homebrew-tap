# fcemtopall/homebrew-tap

Homebrew casks for [fcemtopall](https://github.com/fcemtopall)'s apps.

## sAlive

Keep your Mac awake from Control Center – even with the lid closed.
Mac'ini Denetim Merkezi'nden uyanık tut – kapak kapalıyken bile.

```sh
brew install --cask fcemtopall/tap/salive
```

Update / güncelle: `brew upgrade --cask fcemtopall/tap/salive` (use the full name – Homebrew only upgrades trusted third-party taps / tam adı kullanın)
Uninstall / kaldır: `brew uninstall --cask salive` (add `--zap` to remove settings)

Source: https://github.com/fcemtopall/sAlive

---

Casks in this tap are updated automatically by each project's release workflow.
